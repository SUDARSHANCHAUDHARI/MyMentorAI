# Mentor Prompts

Use these prompts with ChatGPT or Codex after each lesson. Paste your daily check-in below the prompt.

## Daily Review Prompt

```text
Act as my senior QA/SDET mentor.

Review my Day X API testing update.
Be direct, practical, and specific.

Please provide:
1. A score out of 10
2. What I understood well
3. What I should improve
4. One correction if I misunderstood something
5. One follow-up question I must answer before moving on
6. Decision: move ahead, repeat, or do a repair exercise

My update:
```

## Explain Like a Senior QA Prompt

```text
Explain this API testing concept like you are mentoring a senior QA who is new to API testing:

Concept:

Include:
- Plain English explanation
- Real testing example
- Common mistake
- Interview answer
- One practice question
```

## Debug My API Request Prompt

```text
Help me debug this API request.

Context:
Expected result:
Actual result:
Method:
URL:
Headers:
Body:
Status code:
Response:

Please identify likely causes and suggest a step-by-step debugging path.
```

## Interview Practice Prompt

```text
Act as an API testing interviewer.

Ask me 5 questions about:

Topic:

After I answer, grade each answer and tell me:
- What was correct
- What was missing
- How to make it sound more senior
```

## Portfolio Review Prompt

```text
Review this API testing repo like a hiring manager or senior SDET.

Focus on:
- Clarity
- Test coverage
- Documentation
- Automation readiness
- Portfolio value
- Missing professional touches

Give me prioritized improvements.
```
