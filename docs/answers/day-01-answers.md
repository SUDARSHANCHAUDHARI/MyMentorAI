# Day 1 Answers: API Basics

1. An API is a way for software systems to communicate through defined requests and responses.
2. A client sends requests. A server receives requests, processes them, and returns responses.
3. An endpoint is a specific URL where an API exposes a resource or action.
4. You can inspect URL, method, status code, headers, payload, timing, and response data.
5. JSON is common because it is lightweight, readable, and easy for many languages to parse.
