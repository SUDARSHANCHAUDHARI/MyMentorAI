# Day 7: Week 1 Mini Project

## Objective

Turn Week 1 learning into a small, organized Postman project.

## Build

Create or clean up a Postman collection that includes:

- Users requests
- Posts requests
- Comments requests
- Positive scenarios
- Negative scenarios
- Environment variable usage
- Clear request names

## Suggested Requests

Users:

- Get all users
- Get user by valid ID
- Get user by invalid ID

Posts:

- Get all posts
- Get post by valid ID
- Get posts by user ID
- Create post with valid body
- Update post
- Patch post title
- Delete post

Comments:

- Get all comments
- Get comments by post ID

Negative Scenarios:

- Get missing post
- Send invalid body if supported
- Use unsupported path

## Mini Quiz

1. What did you learn this week that feels useful at work?
2. Which HTTP method is still confusing?
3. Which status code is easiest to misuse?
4. What makes a Postman collection portfolio-ready?
5. What should you improve before Week 2?

## Challenge

Export the collection and environment into:

```text
postman/collections/
postman/environments/
```

Only export after checking that no secrets or real tokens are inside.

## Done When

- Week 1 collection is organized.
- Week 1 review is completed.
- `progress.md` has Day 7 and Week 1 review checked off.
- You can explain your collection like a QA engineer presenting work to a team.
