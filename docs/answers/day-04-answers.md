# Day 4 Answers: Params, Headers, and Body

1. A path parameter is part of the URL path, such as `/users/123`.
2. A query parameter is sent after `?`, such as `/users?role=admin`.
3. A JSON request body goes in the body section of the request.
4. `Content-Type` tells the server what format the request body uses.
5. A Bearer token is usually sent in the `Authorization` header.
