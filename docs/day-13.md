# Day 13: Collection Runner

## Objective

Run a Postman collection as a repeatable suite instead of one request at a time.

## Learn

- Collection Runner
- Run order
- Iterations
- Environment selection
- Passed and failed tests
- Debugging failed runs

## Practice

Run your Week 1 collection or a smaller folder through Collection Runner.

Before running:

- Select the correct environment.
- Confirm variables are safe.
- Check request order if chaining is involved.
- Make sure negative scenarios assert expected failures.

After running, record:

- Number of requests
- Number of tests
- Passed checks
- Failed checks
- One fix or improvement

## Mini Quiz

1. Why use Collection Runner?
2. Why does request order matter for chained tests?
3. What should you check before running with an environment?
4. What is one useful thing to record after a run?
5. Why should failed tests be investigated before rerunning blindly?

## Challenge

Save a short run summary in `journal.md`.
