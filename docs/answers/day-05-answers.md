# Day 5 Answers: Postman Collections

1. A collection is a saved group of API requests.
2. Folders make requests easier to organize by feature, resource, or scenario.
3. A clear request name says what is being tested, such as `Get user by valid ID`.
4. Exported collections should not include secrets because repos can be shared or made public later.
5. It should show organized requests, useful scenarios, variables, and assertions where possible.
