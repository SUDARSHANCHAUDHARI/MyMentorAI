# Day 7 Answers: Week 1 Review

1. `GET`, `POST`, `PUT`, `PATCH`, and `DELETE`.
2. Examples: `200` success, `201` created, `401` unauthenticated, `403` forbidden, `404` not found.
3. A positive scenario uses valid input, such as getting a post by an existing ID.
4. A negative scenario uses invalid input or invalid state, such as getting a missing post.
