# Resources

This repo should stay practical. Use resources to support hands-on work, not replace it.

## Practice APIs

### JSONPlaceholder

Good for:

- HTTP methods
- Basic REST practice
- Posts, users, comments examples

Limitations:

- It does not persist writes like a real production API.

### ReqRes

Good for:

- Login-style examples
- User examples
- Simple auth discussions

Limitations:

- It is intentionally small.

### DummyJSON

Good for:

- Products
- Users
- Carts
- Auth-style examples
- Richer response bodies

Limitations:

- Public practice API behavior may differ from a real company backend.

### Fake Store API

Good for:

- E-commerce portfolio examples
- Products and carts
- Business-friendly scenario naming

Limitations:

- Public demo APIs may not enforce all validations.

## Tools

### Browser DevTools

Use for:

- Seeing real network requests
- Inspecting headers
- Understanding frontend-to-backend traffic

### Postman

Use for:

- Manual API testing
- Collections
- Environments
- Scripts
- Mock servers

### Swagger/OpenAPI

Use for:

- Understanding API contracts
- Reading schemas
- Trying documented endpoints

### Newman

Use for:

- Running Postman collections from the command line
- CI integration

### Playwright API Testing

Use for:

- Code-based API automation
- Test structure
- CI-friendly API regression checks

### GitHub Actions

Use for:

- Running tests automatically on push or pull request

## Learning Rule

For every concept, answer:

- What is it?
- Why does it exist?
- How can it fail?
- How would I test it?
- How would I explain it in an interview?
