# Day 8: Authentication

## Objective

Understand how APIs identify a caller and why authentication failures matter in testing.

## Learn

- Authentication vs authorization
- API keys
- Bearer tokens
- JWT basics
- Cookies and sessions
- Common auth failure responses

## Practice

Use a public practice API such as ReqRes or DummyJSON to explore an auth-style flow.

Record:

- Login endpoint
- Required request body
- Successful response status
- Token or user data returned
- Failed login response

Do not save real tokens or credentials in this repo.

## Mini Quiz

1. What is authentication?
2. What is authorization?
3. What does a bearer token usually represent?
4. Why should tokens not be committed?
5. What is one negative auth scenario?

## Challenge

Create a small table of positive and negative auth scenarios you would test for a login API.
