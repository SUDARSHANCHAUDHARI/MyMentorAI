# Day 8 Answers: Authentication

1. Authentication proves who the caller is.
2. Authorization decides what an authenticated caller is allowed to access.
3. A bearer token usually proves that the caller has already authenticated or has been granted access.
4. Tokens can grant access to systems or data, so committing them can create a security leak.
5. Examples: missing credentials, wrong password, expired token, malformed token, or using a token for the wrong user.
