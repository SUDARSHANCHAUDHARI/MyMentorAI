# Day 14 Answers: Swagger and OpenAPI

1. An API contract describes how an API should behave, including endpoints, inputs, outputs, and expected status codes.
2. Swagger helps testers discover endpoints, request formats, response schemas, and edge cases from the documented contract.
3. A required field must be present for the request or response to match the contract.
4. Examples: required parameters, allowed status codes, enum values, min/max constraints, or response field types.
5. Record the mismatch clearly, reproduce it, and confirm whether the bug is in the API behavior or the documentation.
