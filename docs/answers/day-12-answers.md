# Day 12 Answers: Pre-Request Scripts

1. A pre-request script runs before Postman sends the request.
2. Dynamic values prevent collisions and make repeated test runs more realistic.
3. Too much scripting can make tests hard to read, debug, and maintain.
4. Scripts can create values, set variables, or prepare request data for later extraction and reuse.
5. Real secrets, credentials, private tokens, and sensitive user data should never be stored carelessly.
