# Day 1: API Basics

## Objective

Understand what happens when a client calls an API and how to inspect real network requests.

## Learn

- API
- Client
- Server
- Request
- Response
- Endpoint
- Method
- Status code
- Header
- Body
- JSON

## Practice

1. Open Chrome or another browser.
2. Open DevTools.
3. Go to the Network tab.
4. Visit a normal website.
5. Click one request that looks like API data.
6. Identify:
   - URL
   - Method
   - Status code
   - Request headers
   - Response headers
   - Response body

## Notes To Capture

In `journal.md`, write:

- What request you inspected
- What method it used
- What status code it returned
- What the response looked like
- What confused you

## Mini Quiz

1. What is the difference between a client and a server?
2. What is an endpoint?
3. What does a status code tell you?
4. Why do APIs often use JSON?
5. What part of DevTools helps you inspect API calls?

## Challenge

Find one request that returns JSON and explain it in plain English.
