# Mistakes Log

Track mistakes and debugging lessons here. These become strong interview stories.

Common examples worth recording:

- Expected the wrong status code
- Forgot an authorization header
- Sent invalid JSON
- Used the wrong HTTP method
- Confused path params and query params
- Did not reset test data
- Wrote an assertion that was too weak
- Wrote an assertion that was too brittle
- Missed a negative scenario
- Did not read the API contract carefully

Date:

Mistake:
