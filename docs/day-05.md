# Day 5: Postman Collections

## Objective

Organize API requests in Postman so they are reusable, readable, and portfolio-friendly.

## Learn

- Collections
- Folders
- Request naming
- Descriptions
- Export/import
- Collection-level variables

## Practice

Create a Postman collection named:

```text
API Testing Bootcamp - Week 1
```

Add folders:

- Users
- Posts
- Comments
- Negative Scenarios

Add at least:

- 2 user requests
- 3 post requests
- 2 comment requests
- 2 negative scenario requests

## Mini Quiz

1. Why are collections useful?
2. Why should request names be clear?
3. What is the benefit of folders?
4. Why should exported collections avoid secrets?
5. What makes a collection easy for another tester to understand?

## Challenge

Rename every request so it reads like a test case.

Example:

```text
Get post by valid ID
Get post by missing ID
Create post with valid body
```

## Done When

- Your Postman collection is organized into folders.
- Requests have clear names.
- You understand how to export the collection.
- `progress.md` has Day 5 checked off.
